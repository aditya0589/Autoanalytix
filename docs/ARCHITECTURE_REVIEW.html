Problem

Three API controllers manually coordinate six shallow modules and temporary CSV disk serialization to ingest data.

Solution

Consolidate parsing, profiling, Parquet persistence, and engine registration behind one deep DatasetIngestion module.

Problem

The analytics engine requires callers to manually orchestrate S3 cache hydration and table registration before querying.

Solution

Deepen the engine module to resolve and hydrate datasets automatically behind a single query interface.

Wins
  • ✓ Locality: cache synchronization stays internal
  • ✓ Prevents agent cold-start crashes completely
  • ✓ Leverage: one interface for all callers
  • ✓ Tests hit one in-memory seam
